# ScanBite — Brand Kit

Complete brand identity and design assets for ScanBite.

## Files included

| File | Description |
|------|-------------|
| `scanbite-landing.html` | Full landing page — hero, how it works, features, pricing, testimonials, CTA, footer |
| `scanbite-brand-identity.html` | Brand identity system — logo (light + dark), color palette, typography, taglines, brand voice |
| `scanbite-icons-favicon.html` | App icon at all sizes (1024px, 80px, 48px) + favicon (32px, 16px) + iOS home screen preview |
| `scanbite-menu-mockup.html` | Restaurant QR menu mockup — mobile customer view + printable table QR card |

## Brand Overview

**Name:** ScanBite  
**Tagline:** Scan it. See it. Eat it.  
**Category:** Digital QR menu platform for restaurants, cafés, and street food vendors

## Typography

- **Display:** Bebas Neue (bold headlines)
- **Body:** DM Sans (300 light / 400 regular / 500 medium / 700 bold)
- **Mono:** DM Mono (URLs, codes, labels)

## Fonts (Google Fonts)

```html
<link href="https://fonts.googleapis.com/css2?family=Bebas+Neue&family=DM+Sans:wght@300;400;500;700&family=DM+Mono:wght@400;500&display=swap" rel="stylesheet">
```

## How to use

All files are standalone HTML — open directly in any browser. No build step or dependencies required beyond Google Fonts (loaded via CDN).
